# 素材接入规范（asset-spec）

本文档说明如何制作并替换角色素材包。**替换素材不需要改任何代码**：按规范放置文件、填写 manifest，重启应用即生效。

## 素材包位置

```
assets-app/<角色目录>/
```

应用默认加载 `assets-app/default/`。替换角色 = 替换该目录内容（或修改 `app/main/main.js` 中的 `ASSETS_ROOT` 指向新目录——通常不需要）。

## 目录结构

```
default/
├── manifest.json        # 清单（必需，唯一入口）
├── poses/               # 立绘（透明背景 PNG）
│   ├── idle.png
│   └── happy.png
├── gaze/                # 视线方向帧（完整帧，见下文对齐要求）
│   ├── g0r0.png … g2r2.png   # 3×3 时 9 张；5×5 时 25 张
├── blink/               # 眨眼覆盖帧（全画布、只含眼睑）
│   ├── half.png
│   └── closed.png
├── mouth/               # 口型覆盖帧（全画布、只含嘴部）
│   ├── half.png
│   └── open.png
└── audio/
    └── test.wav         # 本地测试音（可选）
```

## manifest.json 字段说明

```jsonc
{
  "name": "角色名",
  "version": 1,
  "canvas": { "width": 600, "height": 800 },   // 声明画布尺寸（所有帧必须一致）
  "poses": [
    { "id": "idle", "name": "待机", "src": "poses/idle.png" }
  ],
  "gaze": {
    "pose": "idle",              // 方向帧基于哪个姿态录制
    "cols": 3, "rows": 3,        // 方向网格：3×3 或 5×5
    "srcPattern": "gaze/g{c}r{r}.png"  // {c}=列(左→右) {r}=行(上→下)
  },
  // 方式A（基础）：全局帧，适用于无头部微动的素材包
  // 方式B（推荐，视线帧带头部微动时必须）：每方向一套眨眼/口型帧
  "blink": {
    "perGaze": true,                            // 启用每方向模式
    "patterns": {
      "1": "blink/g{c}r{r}_half.png",           // 1=半闭（可选，缺图自动回退全局帧）
      "2": "blink/g{c}r{r}.png"                 // 2=全闭
    }
  },
  "mouth": {
    "perGaze": true,
    "patterns": {
      "1": "mouth/g{c}r{r}_half.png",           // 1=半开（可选）
      "2": "mouth/g{c}r{r}.png"                 // 2=全开
    }
  },
  // 方式A 写法（与方式B 二选一或并存作为回退）：
  // "blink": { "frames": [ { "level": 1, "src": "blink/half.png" }, { "level": 2, "src": "blink/closed.png" } ] },
  "themes": {
    "day":   { "name": "日间", "starCount": 0 },
    "night": { "name": "夜间", "starCount": 60 }  // 夜间星光数量
  },
  "testAudio": "audio/test.wav"
}
```

所有可选项都可以省略，省略后对应功能自动禁用（降级不报错）：没有 `gaze` 则视线跟随停用；没有 `blink` 则不眨眼；没有 `mouth` 则口型不动。

## 用 Live2D Cubism 录制素材的方法

在动画工作区（或参数面板）逐参数导出 PNG 序列：

1. **画布与位置锁定**：所有导出使用同一场景尺寸；除目标参数外，其余参数归零、模型位置固定。
2. **立绘**：摆好完整姿势（含默认表情），导出 1 张/姿态。
3. **视线方向帧**：只调整视线/头部朝向参数，按网格逐格导出（如 3×3：左中右 × 上中下）。导出的是**完整角色帧**。
4. **眨眼覆盖帧**：隐藏除眼睑/睫毛外的全部图层（含张开的眼球），导出半闭、全闭两张。全画布导出，眼睑位置自然盖住底图上的眼睛。
5. **口型覆盖帧**：隐藏除嘴部外的全部图层，按张合度导出 2～4 张。
6. 全部导出为 **透明背景 PNG**，与 SVG 占位素材同名放置，更新 manifest 中的引用。

## 对齐要求（重要）

- 所有帧**画布尺寸完全一致**；
- 同一角色的各帧之间除目标变化外**逐像素对齐**，否则运行时角色会抖动；
- 覆盖帧（眨眼/口型）必须与底图同一画布坐标系。

## 音频

- 测试音：WAV/MP3 均可，建议 1～2 秒、含响度起伏（便于验证口型）。
- TTS 回复音频由用户配置的 TTS 服务实时合成，不在素材包内。

## 版权要求
