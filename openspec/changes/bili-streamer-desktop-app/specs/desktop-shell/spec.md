# desktop-shell 规格（增量）

## Purpose

定义桌面宠物应用壳的外部行为：应用以悬浮于桌面之上的透明角色窗口形态运行，角色可拖动、区域外不挡操作，同时具备常规桌面应用的托盘与打包交付能力。用户感知是"桌面上住着一个角色"，而非"打开了一个网页或软件界面"。

## ADDED Requirements

### Requirement: 桌面宠物窗口形态

主窗口必须为透明、无边框、始终置顶的悬浮窗；启动后角色显示在屏幕上，不显示网页地址栏、页面滚动条等浏览器痕迹。主界面（设置、对话字幕）按需弹出，不常驻遮挡桌面。

#### Scenario: 启动即桌面宠物
- **WHEN** 用户双击启动应用
- **THEN** 角色以透明悬浮形态出现在桌面置顶层，无窗口边框与背景色块

### Requirement: 角色拖动与位置记忆

用户必须能用鼠标按住角色拖动到屏幕任意位置；拖动过程中角色跟手移动。应用重启后角色必须出现在上次拖到的位置。

#### Scenario: 拖动到屏幕角落
- **WHEN** 用户按住角色拖到屏幕右下角后松开并重启应用
- **THEN** 角色出现在右下角上次位置

### Requirement: 角色区域外鼠标穿透

鼠标位于角色形象之外的区域时，点击必须穿透窗口直达下层桌面/其他应用；鼠标位于角色形象之上时，可正常与角色交互（拖动、点击）。应用不得在角色之外的区域形成不可见的鼠标阻挡。

#### Scenario: 穿透点击桌面图标
- **WHEN** 鼠标移到角色旁边（非角色身体区域）双击桌面图标
- **THEN** 图标正常打开，点击未被应用拦截

#### Scenario: 角色区域可交互
- **WHEN** 鼠标移到角色身上并按住拖动
- **THEN** 角色跟手移动，不发生穿透

### Requirement: 系统托盘

应用必须在系统托盘显示图标，托盘菜单至少提供：显示/隐藏角色、打开设置、退出。退出必须通过托盘菜单，且结束时停止一切播放与录音。

#### Scenario: 托盘退出
- **WHEN** 用户在托盘菜单选择"退出"
- **THEN** 应用进程完全结束，录音与播放停止

### Requirement: 打包交付

项目必须能通过一条构建命令产出 NSIS 安装包与免安装便携版两个 Windows 交付物；产物在 64 位 Windows 10/11 上双击即用，不要求用户安装 Node.js、Python 或任何运行时。

#### Scenario: 全新机器安装
- **WHEN** 在一台无开发环境的 Windows 11 机器上安装并启动应用
- **THEN** 桌面宠物正常显示，设置、语音聊天功能全部可用
