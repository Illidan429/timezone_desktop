# avatar-display 规格（增量）

## Purpose

定义角色在透明宠物窗口中的呈现行为：立绘渲染、视线跟随鼠标、待机眨眼、口型渲染与日夜主题。角色由图片素材（立绘、方向集、眨眼帧、口型帧）构成，行为约定不依赖特定素材，素材缺失时有明确降级。

## ADDED Requirements

### Requirement: 立绘展示与姿态切换

主界面（宠物窗口）必须展示当前角色的立绘；素材包定义了多套立绘/姿态时，用户必须能通过托盘菜单或界面切换，默认姿态在启动时自动加载。素材缺失或损坏时不得白屏或崩溃，回退到内置占位形象并提示。

#### Scenario: 启动加载默认立绘
- **WHEN** 应用启动完成且素材包含有效立绘
- **THEN** 透明窗口中显示默认立绘，无闪烁、无背景色块

#### Scenario: 素材缺失降级
- **WHEN** 素材包损坏或被删除后启动应用
- **THEN** 显示内置占位形象与提示，应用其余功能可用

### Requirement: 视线跟随鼠标

角色视线必须跟随鼠标方向变化：依据鼠标相对角色的方位切换朝向素材帧（方向集），并叠加细微位移/倾斜增强自然感；切换平滑无跳变，鼠标静止 2 秒后视线回到正前方。视线跟随在整个屏幕范围内有效。

#### Scenario: 鼠标绕角色移动
- **WHEN** 鼠标围绕角色从左侧缓慢移动到右侧
- **THEN** 角色朝向随方位连续变化，无跳帧感

### Requirement: 待机眨眼

角色空闲时必须按素材定义的眨眼帧序列自动眨眼（闭合—半开—睁开），间隔含随机性，不呈现机械固定周期。

#### Scenario: 待机自动眨眼
- **WHEN** 应用空闲观察 1 分钟
- **THEN** 角色发生多次眨眼，相邻间隔不完全相同

### Requirement: 口型渲染

角色的口型帧必须由正在播放的音频实时驱动：开口幅度随响度变化，音频停止后 300ms 内闭合；未播放音频时保持闭口。

#### Scenario: 说话口型
- **WHEN** 一段含响度起伏的语音播放中
- **THEN** 角色口型开合幅度随响度变化，播放结束即闭合

### Requirement: 日夜主题

应用必须提供日间与夜间两套呈现主题（含角色周边氛围元素差异，如夜间星光）；用户切换后选择持久化，重启保持。

#### Scenario: 切换主题并重启
- **WHEN** 用户切换到夜间主题后重启应用
- **THEN** 应用仍以夜间主题呈现
