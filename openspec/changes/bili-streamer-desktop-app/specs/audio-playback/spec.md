# audio-playback 规格（增量）

## Purpose

定义应用内音频播放的行为：语音/音频队列、播放控制、音量、内置测试音，以及播放状态如何驱动口型同步。音频来源可以是 Agent 推送（经 `agent-api`）或用户本地试听。

## ADDED Requirements

### Requirement: 播放队列

音频请求必须按顺序进入播放队列并依序播放；队列中的条目可被"停止并清空"操作一次性终止。正在播放的条目不受新入队条目影响。

#### Scenario: 依序播放
- **WHEN** Agent 在 1 秒内连续推送 3 条语音
- **THEN** 3 条语音按推送顺序依次完整播放，不重叠

#### Scenario: 停止并清空
- **WHEN** 用户（或 Agent）触发停止并清空
- **THEN** 当前播放立即停止，队列清空，口型恢复闭合

### Requirement: 音量控制

用户必须能在界面调节播放音量（0–100%），调节立即生效于当前与后续播放，并持久化到下次启动。

#### Scenario: 调节音量立即生效
- **WHEN** 播放过程中用户将音量从 100% 调到 30%
- **THEN** 当前正在播放的音频音量随之降低，无爆音

### Requirement: 内置测试音

应用必须内置不依赖任何外部服务的测试音频，用户可一键试听以验证扬声器输出与口型同步是否正常；测试音不进入 Agent 对话上下文。

#### Scenario: 首次使用验声
- **WHEN** 用户点击"测试音"按钮
- **THEN** 播放内置测试音，角色口型随音频同步开合

### Requirement: 口型同步驱动

正在播放的语音必须实时驱动角色口型开合，口型幅度反映音频瞬时响度；音频结束后口型在 300ms 内回到闭合。无音频播放时口型保持闭合。

#### Scenario: 语音驱动口型
- **WHEN** 一段包含响度起伏的语音正在播放
- **THEN** 角色口型开合幅度随响度变化，语音结束后口型闭合
