# asset-pipeline 规格（增量）

## Purpose

定义角色图片素材的接入规范：素材包目录结构、manifest 清单格式、加载与降级行为。目标是代码与素材彻底分离——替换主播角色 = 替换素材包，不改代码；素材未到位时用自绘占位素材包开发，不阻塞。参考项目素材**不得**复制进本项目，此规范只约束本项目素材包的组织方式。

## ADDED Requirements

### Requirement: manifest 清单驱动

素材包必须包含一个 manifest 清单文件，声明角色名、立绘/姿态列表、方向集（视线朝向帧）、眨眼帧序列、口型帧映射、主题背景、测试音等全部素材入口；应用只依据清单加载素材，代码中不硬编码任何具体素材文件名。清单缺字段时应用必须在启动日志与界面提示具体缺失项。

#### Scenario: 仅凭清单换角色
- **WHEN** 素材制作者按规范替换整个素材包并调整 manifest
- **THEN** 应用无需改代码即展示新角色

#### Scenario: 清单字段缺失提示
- **WHEN** manifest 缺少眨眼帧声明
- **THEN** 应用启动时给出指明缺失字段的提示，并以无眨眼状态降级运行

### Requirement: 标准目录结构

素材包必须遵循固定的目录结构（立绘、方向集、眨眼帧、口型帧、主题、音频各自独立目录），结构文档随项目交付；目录组织与参考项目保持概念对齐（方向集、眨眼帧等命名方式），便于素材制作者参照产出。

#### Scenario: 素材制作者按文档交付
- **WHEN** 素材制作者按结构文档放置文件并填写清单
- **THEN** 应用能直接加载，无需开发者介入调整

### Requirement: 占位素材包

项目必须自带一套自绘占位素材包（结构完整、体积小、无版权争议），使全部功能在正式素材到位前即可开发、测试与演示；占位素材与正式素材通过替换素材包目录切换，无需改动代码或构建配置。

#### Scenario: 无正式素材开发演示
- **WHEN** 使用占位素材包运行应用
- **THEN** 立绘、视线跟随、眨眼、口型、主题、语音聊天全部可演示

### Requirement: 素材版权隔离

项目仓库与分发包中不得包含参考项目的任何素材文件；正式素材必须在取得授权后才能入库/分发，授权来源记录在素材包说明文件中。

#### Scenario: 仓库检查
- **WHEN** 对代码仓库执行内容检查
- **THEN** 不存在与参考项目素材同名的资源文件

### Requirement: 缺失与损坏降级

单个素材文件缺失或损坏时，应用必须跳过该素材并在界面提示，不影响其余素材与功能运行：立绘缺失回退占位形象，眨眼帧缺失禁用眨眼，口型帧缺失禁用口型动画，音频缺失禁用对应试听项。

#### Scenario: 单文件损坏不影响整体
- **WHEN** 素材包中某一帧眨眼图片损坏
- **THEN** 应用禁用眨眼动画并提示，其余功能正常
