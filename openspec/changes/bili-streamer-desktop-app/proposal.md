# 提案：B 站主播桌面宠物（图片立绘 + 语音聊天）

## Why

用户要为一位 B 站主播做一个桌面伴侣应用，核心诉求有三：**① 桌面宠物形态**——角色悬浮在桌面上、可拖到任意位置；**② 眼神跟随鼠标**；**③ 语音聊天**——对角色说话或打字，角色用声音回复。参考项目（`reference/midori-companion-avatar-main/`）验证了「PNG 立绘 + 帧动画 + 音频口型」方案的可行性，本项目的角色渲染沿用同类方案（曾评估 Live2D，因模型文件随应用分发即等于泄露、且再分发授权受限而放弃）；参考项目"Python 起服务 + 浏览器打开"的交付方式则不沿用，改为独立桌面应用。

## What Changes

- 从零新建**图片立绘桌面宠物应用**（Electron）：
  - **桌面宠物形态**：透明无边框、置顶窗口；角色可拖动到桌面任意位置，位置记忆；角色区域外鼠标点击穿透到桌面，不挡操作
  - **角色呈现**（参考项目同构的图片方案）：PNG 立绘展示与姿态切换、视线跟随鼠标（方向集选帧 + 微位移）、待机眨眼帧动画、日夜主题、口型帧随音频响度开合
  - **语音聊天**：麦克风收音 → 语音识别（ASR）→ 大模型（LLM）→ 语音合成（TTS）→ 播放 + 口型 + 字幕；**API 由用户在设置页自行配置**（OpenAI 兼容格式），**每类 API 配置带"测试"按钮**验证可用性；**按键说话 / 免提监听 / 文字输入三种交互模式可切换**
  - 音频播放队列、音量控制、无 API 可用的本地测试音
- 素材与代码分离：素材包以清单（manifest）驱动加载，换角色不改代码；首版自带自绘占位素材开发
- 交付：NSIS 安装包 + 便携版，Windows 10/11 双击即用
- 参考项目的 Agent HTTP 接口、歌词舞台、星空特效、B 站弹幕互动等**不在本期范围**，列为后续迭代

## Capabilities

### New Capabilities

- `desktop-shell`: 桌面宠物壳——透明置顶无边框窗口、角色拖动与位置记忆、区域外鼠标穿透、系统托盘、打包交付
- `avatar-display`: 角色呈现——立绘渲染与姿态切换、视线跟随、待机眨眼、口型渲染、日夜主题、素材缺失降级
- `voice-chat`: 语音聊天——API 配置与测试按钮、三种交互模式（按键说话/免提/打字）切换、ASR→LLM→TTS 链路、对话上下文、字幕与打断
- `audio-playback`: 音频播放——TTS 播放队列、音量控制、测试音、响度驱动口型
- `asset-pipeline`: 素材接入——素材包目录与清单规范、占位素材包、损坏降级、版权隔离

### Modified Capabilities

（无——本项目尚无既有规格）

## Impact

- **新增代码**：仓库根新建 `app/`（Electron 主进程 + 渲染端）与 `assets-app/`（素材包，运行时加载）；`package.json` 引入 electron、electron-builder、vite 等
- **对外依赖**：应用出站网络请求仅发往**用户配置**的 ASR/LLM/TTS 服务地址；API Key 本地加密存储、界面不回显
- **素材版权**：图片素材由项目方制作或取得授权后打包分发（图片方案下素材随应用分发，授权责任在素材来源，需在素材到位前确认）；参考项目素材仍然不可复制
- **不受影响**：`reference/`（只读参考）、`openspec/` 工作流
