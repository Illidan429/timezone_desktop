# voice-engine 规格（增量）

## Purpose

定义 GPT-SoVITS 推理引擎作为"分离式语音包"的完整生命周期行为：引擎包的下载、校验、解压与版本管理，以及引擎 HTTP 服务子进程的启动、探活、端口分配、崩溃恢复与退出清理。用户感知为"一键获得本地语音引擎，无需安装 Python 或任何开发环境"。

## ADDED Requirements

### Requirement: 引擎包下载

用户必须能通过一键操作下载语音引擎包（ZIP，含嵌入式 Python 运行时、GPT-SoVITS 推理代码与基础模型）；下载地址从设置中读取（由委托人配置），支持自定义镜像地址。下载过程必须显示进度（百分比/已下载大小），中断后可重新下载；下载完成后校验完整性（大小/可选哈希）并自动解压到应用数据目录，解压失败须清理残留并提示原因。

#### Scenario: 一键下载并解压
- **WHEN** 用户在设置中点击"下载语音引擎"，下载源可访问
- **THEN** 显示下载进度，完成后自动解压并进入"已安装"状态，无需用户任何手动操作

#### Scenario: 下载中断可重试
- **WHEN** 下载过程中网络中断
- **THEN** 界面提示失败原因，可重新点击下载；不留损坏的半截包进入"已安装"状态

### Requirement: 引擎服务生命周期

应用必须在首次需要语音合成时自动启动引擎服务（GPT-SoVITS api_v2），并管理其完整生命周期：启动后轮询探活直到就绪（含模型加载的 10~60 秒窗口，期间状态可见）；默认端口被占用时自动顺延到可用端口；引擎进程意外退出时有限次自动重启（上限 3 次，超出后进入错误态并提示）；应用退出时必须终止引擎进程，不留孤儿进程。

#### Scenario: 首次合成自动拉起引擎
- **WHEN** 引擎已安装但未运行，用户发起一次需要语音合成的对话
- **THEN** 界面显示"语音引擎启动中"，引擎就绪后合成继续，全程无需用户干预

#### Scenario: 端口冲突自动顺延
- **WHEN** 默认端口被其他程序占用
- **THEN** 引擎自动改用下一个可用端口并正常工作

#### Scenario: 应用退出不留孤儿进程
- **WHEN** 用户通过托盘退出桌宠
- **THEN** 引擎子进程随之一并结束

### Requirement: 引擎状态可见

应用必须在设置页展示引擎的当前状态（未下载/下载中/已下载未运行/启动中/就绪/错误及原因）；语音流程中因引擎未就绪导致的等待也必须以明确文案呈现（如"语音引擎启动中，首次需加载模型"），不得静默卡住。

#### Scenario: 状态一目了然
- **WHEN** 用户打开设置页的语音引擎区块
- **THEN** 当前状态与可执行操作（下载/修复/启动）清晰可见，错误态附带具体原因
