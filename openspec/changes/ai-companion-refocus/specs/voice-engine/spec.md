# voice-engine 规格（增量）

## Purpose

定义 GPT-SoVITS 本地推理引擎包的获取与生命周期管理：用户无需手动部署 Python 环境即可获得本地语音合成能力，引擎对用户表现为设置页中的一个可管理组件。

## ADDED Requirements

### Requirement: 引擎包下载与安装

应用必须支持在设置页一键下载 GPT-SoVITS 推理引擎包（ZIP：嵌入式 Python 运行时 + 推理代码 + 基础模型），自动解压到本地用户目录并校验完整性；下载源地址必须可在设置中配置（由委托人托管分发）；安装失败或文件损坏时必须支持重新下载/修复，不得要求用户手动清理目录。

#### Scenario: 一键下载安装
- **WHEN** 用户在设置页点击下载引擎包并等待完成
- **THEN** 引擎自动解压校验并进入"启动中/就绪"状态，全程无需用户手动操作

#### Scenario: 下载失败可修复
- **WHEN** 引擎包下载中断或校验失败
- **THEN** 界面提示失败原因，用户可重新发起下载并成功完成安装

### Requirement: 引擎进程生命周期

主进程必须以子进程方式管理 api_v2 HTTP 服务的启动与停止：默认端口被占用时自动顺延；启动后必须就绪探活（引擎首次加载模型可达数十秒，期间状态可见）；引擎崩溃时自动重启（有限次，超过后进入错误态并提示）；应用退出时引擎子进程必须随之停止。

#### Scenario: 端口冲突自动顺延
- **WHEN** 默认端口已被其他程序占用时启动引擎
- **THEN** 引擎自动改用其他可用端口并正常就绪

#### Scenario: 崩溃自动重启
- **WHEN** 引擎子进程意外退出且未超过重启次数上限
- **THEN** 应用自动重启引擎并恢复就绪，用户无感知

#### Scenario: 退出时停止引擎
- **WHEN** 用户退出应用
- **THEN** 引擎子进程随之结束，不残留后台进程

### Requirement: 引擎状态可见

引擎状态（未下载 / 下载中 / 启动中 / 就绪 / 错误）必须在设置页实时可见；当引擎未就绪时用户发起语音合成，应用必须行内提示当前状态与原因，不得静默无响应。

#### Scenario: 未就绪时合成提示
- **WHEN** 引擎尚在"启动中"时用户发起对话并要求语音回复
- **THEN** 界面行内提示引擎正在启动，文字回复正常展示，不卡死不静默
