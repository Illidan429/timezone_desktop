# voice-model 规格（增量）

## Purpose

定义固定目标音色的模型管理与 TTS 提供方式：用户导入委托人分发的预训练音色模型后，零配置获得固定目标音色的本地语音合成；本变更范围为单一固定音色，不包含音色克隆与多音色切换。

## ADDED Requirements

### Requirement: 音色模型导入与启用

用户必须能在设置页一键导入委托人分发的 GPT/SoVITS 预训练权重并启用；必须提供试听（用固定示例文本合成一段播放）；导入与启用状态持久化，重启后仍生效。本机引擎模式下必须使用当前已启用的模型输出固定目标音色。

#### Scenario: 导入并试听
- **WHEN** 用户选择模型文件完成导入并点击试听
- **THEN** 应用合成并播放一段固定示例文本，音色为目标音色

#### Scenario: 重启后仍生效
- **WHEN** 用户启用模型后重启应用并试听
- **THEN** 无需重新导入，试听仍为该模型音色

### Requirement: TTS 提供方式与默认路线

TTS 类型必须可选"GPT-SoVITS（本机引擎）"与"OpenAI 兼容（云端）"，两者配置均保留；在引擎就绪的前提下默认使用本机引擎（固定目标音色）。选择本机引擎但引擎未就绪（未下载/启动中/错误）时，对话请求必须行内提示原因与前往处理的入口，不得静默失败，也不得未经用户确认自动回退云端。

#### Scenario: 默认本机引擎合成
- **WHEN** 引擎就绪且用户未改过 TTS 类型，用户发起对话
- **THEN** 语音回复由本机引擎以固定目标音色合成

#### Scenario: 未就绪不静默不擅自回退
- **WHEN** 引擎未下载时用户发起对话
- **THEN** 界面提示引擎未就绪及原因，文字回复正常展示，不自动改用云端音色

### Requirement: 合成接入对话链路

本机引擎合成的语音必须接入现有播放队列，播放期间口型同步、字幕/气泡展示，行为与云端 TTS 一致；合成期间状态可见，失败时行内提示并保持应用可用。

#### Scenario: 对话回复口型同步
- **WHEN** 用户语音提问且引擎合成完成
- **THEN** 角色开口播报回复、口型同步、字幕同步展示，与云端 TTS 路线体验一致
