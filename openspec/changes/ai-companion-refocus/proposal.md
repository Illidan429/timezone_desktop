# 提案：重新聚焦 AI 陪伴桌宠（视线跟随 + 固定音色聊天）

## Why

应用最初面向 B 站主播场景铺开功能，语音聊天 UI 已按需暂停。用户现重新明确产品定位，核心体验收敛为两条主线：**人物盯着鼠标**（视线跟随，已实现，是陪伴感的基础）与**使用固定目标音色的聊天**（此前云端 TTS 预设音色无法还原目标音色，需以本地 GPT-SoVITS 预训练音色模型解决）。需要一次重新规划，把聊天功能以固定目标音色的形态恢复，并补齐让聊天"像这个角色在说话"的人设能力。

## What Changes

- **产品定位重聚焦**：应用收敛为"AI 陪伴桌宠"。两条核心主线：①人物视线盯着鼠标——已实现（九方向视线帧 + 头身姿态变换），保留为持续打磨的基础交互，本变更不改动其需求；②固定目标音色聊天——本变更重建。
- **恢复聊天功能 UI**：恢复此前按需卸载的聊天操作栏与字幕框，三种输入模式（按键说话 / 免提监听 / 文字输入）回归。底层 pipeline / recorder / player 模块一直保留在仓库中，主要是重新装配与回归验证。
- **固定目标音色（简化原"双音色模式"提案）**：TTS 以本地 GPT-SoVITS 引擎 + 委托人分发的预训练音色模型为**默认路线**，用户零配置获得固定目标音色；原 `gpt-sovits-voice-engine` 提案中的"零样本克隆"移出本期（列为后续迭代），"双音色模式"简化为"固定单音色"。云端 OpenAI 兼容 TTS 保留为备选类型。
- **聊天人设**：新增角色人设（system prompt）能力：设置页可编辑、默认内置人设、持久化；所有 LLM 对话注入人设，让回复符合角色性格。
- **既有变更关系**：
  - 本变更**取代** `gpt-sovits-voice-engine`（其 `voice-engine` / `voice-model` 规格经简化后由本变更重新声明；该变更归档时**不合并**其规格增量）。
  - `bili-streamer-desktop-app` 的规格（含 voice-chat、avatar-display）先行归档落地；本变更**只增不改性**。其挂起的语音验收项（6.3 / 6.4 / 6.6）在本变更恢复聊天 UI 后随之解锁。
- **保留不变**：桌面形态基础能力（拖动、点击穿透、托盘、多显示器校准、大小调节）、素材管线、播放与口型同步链路。

## Capabilities

### New Capabilities

- `persona`: 聊天角色人设——人设提示词的配置、持久化、默认内置与注入 LLM 对话。
- `voice-engine`: GPT-SoVITS 引擎包管理与子进程监督——引擎包下载/校验/解压/版本管理，api_v2 子进程启动、探活、端口冲突顺延、崩溃有限次重启、随应用退出停止，引擎状态可见（承接被取代变更的既有设计）。
- `voice-model`: 固定目标音色——委托人预训练音色模型（单一固定音色）的导入/启用/试听，TTS 提供方扩展为"GPT-SoVITS（本机引擎）"并设为默认，合成接入现有播放队列与口型同步。

### Modified Capabilities

（无——主规格库当前为空。voice-chat、avatar-display、audio-playback、desktop-shell 等能力随 `bili-streamer-desktop-app` 归档落地，本变更不修改其需求级行为；本机 GPT-SoVITS 作为 TTS 的一种提供方式接入，voice-chat 的"TTS 为用户配置的服务"需求不变。）

## Impact

- **恢复性改动**：`app/renderer/pet/`（聊天操作栏、字幕框重新装配）、设置页（人设编辑区、语音引擎区块、TTS 类型选项）。
- **新增代码**：主进程引擎管理模块（下载/解压/子进程监督）与 GPT-SoVITS api_v2 客户端；LLM 消息构造处注入人设（`proxy.chatComplete` 的调用方）；TTS 调用层增加 provider 分支。
- **依赖**：仅使用 Node 内置能力（下载/解压/子进程），不引入重型依赖；GPT-SoVITS 为 MIT 许可，需在 CREDITS 署名。
- **分发**：语音引擎包（约 2~3GB，含嵌入式 Python 运行时）与音色模型由委托人托管分发，安装包体积不变。
- **风险**：引擎首次加载模型需 10~60 秒（必须异步化并反馈状态）；纯 CPU 推理约 5~15 秒/句（需在 UI 提示预期）；大体积下载需校验与修复入口。
- **规划假设（评审时请确认）**：①聊天保留三种输入模式（模块已在，恢复成本低，如只需文字聊天可在评审时裁掉语音输入）；②"固定目标音色"指委托人提供的 GPT-SoVITS 预训练模型（延续已确认的音色还原路线）；③语音识别（ASR）仍走用户自行配置的 OpenAI 兼容服务，不在本期内本地化。
